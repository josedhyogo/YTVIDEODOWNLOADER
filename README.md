# ▶️YTVIDEODOWNLOADER
Aplicação **Python** que realiza download de vídeos/músicas, em playlists ou não, em um local indicado pelo usuário. 
O projeto possui uma **interface gráfica** que permite escolher o formato de arquivo (Áudio ou Vídeo), escolher as pastas de destino (incluindo unidades externas: Pendrives,HDs externos, etc.) e inserir URL.

## 🚀 Funcionalidades

* Download automático de vídeos ou áudios do YouTube,YouTube Music e Instagram;
* Interface gráfica com **PySimpleGUI**;
* Permite escolher as pastas de destino;
* Permite utilizar pastas que já existem;
* Barra de progresso durante o download;
